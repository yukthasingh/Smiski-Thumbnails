# Smiski-Thumbnails
A fun, lightweight Google Chrome extension (Manifest V3) that injects tiny randomized Smiski figurines into Youtube video thumbnails!

**Disclaimer**: @yukthasingh does not own Smiski; Smiski is a standalone japanese figurine company. Information about their works can be found on https://smiski.com/e/ 

## Features
- **Randomized spawning**: Smiskis appear in random corners of video thumbails
- **Dynamic loading support**: Leverages `MutationObserver` to ensure continous thumbnail coverage as you scroll down Youtube's infinite feed
- **Popup control menu**: Easily enable or disable the extension at the click of a button located in the extension itself
- **Instate state sync**: Changes in the popup menu update open Youtube tabs in real-time 
- **Click through transparency**: The appearences of Smiskis do not interfere with typical YouTube actions, such as clicking on videos
